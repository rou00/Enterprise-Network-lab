# Enterprise-Network-lab (Multi-Department)
Enterprise multi-VLAN network project using Cisco Packet Tracer
Simulation of an enterprise multi-department network.

## Features
- VLAN segmentation
- Inter-VLAN Routing
- ACL security rules
- DHCP configuration
- SSH remote management
- RIP v2 routing
- Guest WiFi isolation

## Departments
- Administration
- IT
- HR
- Sales
- Servers
- Guest WiFi

## Servers
- DNS Server
- Web Server
- FTP Server
- Mail Server

## Technologies Used
- Cisco Packet Tracer
- Cisco IOS CLI
- VLANs
- ACLs
- DHCP
- Routing
